# Pommu X Embed

[Pommu](https://ch.dlsite.com/pommu/) の投稿内にある x.com(twitter.com)のポストリンクを、投稿内に埋め込み表示する Tampermonkey 用ユーザースクリプトです。

## 機能

- 投稿内の x.com / twitter.com のポストリンクを検出し、リンクの下にポストのカードを表示
  - 投稿者名・ID・アイコン、本文、画像・動画・GIF、投稿日時
- **引用リポスト**の場合は、引用元のポストもカード内に表示
- 本文が長い場合は約5行で折りたたみ、「続きを読む」/「閉じる」で開閉(引用部分も同様)
- 1つの投稿に複数のリンクがある場合は順に並べて表示(同じポストの重複表示はしない)
- ポストを取得できない場合(削除・非公開など)は「x.comで開く」リンクを表示
- 元のリンクはそのまま残します
- ページ遷移やタイムラインの追加読み込みにも対応

## インストール

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) を入れる
2. 下のリンクを開き、インストールを選ぶ

   [pommu-x-embed.user.js をインストール](https://raw.githubusercontent.com/4STRA1/pommu-x-embed/main/pommu-x-embed.user.js)

3. 初回の実行時に外部通信(`api.fxtwitter.com`)の許可を求められたら許可する

`@updateURL` を設定しているので、リポジトリ側で `@version` が上がると Tampermonkey の更新確認で自動的に更新されます。

## 対象ページ

`https://ch.dlsite.com/pommu/*`

## 仕組みとプライバシー

ポストの内容は [FxTwitter](https://github.com/FxEmbed/FxEmbed) の API(`api.fxtwitter.com`)から取得しています。表示のたびに、ポストのURL(ユーザー名とポストID)がこのサービスに送信されます。X 公式の埋め込みスクリプトは使っていません。

## 注意事項

- 外部サービスに依存しているため、API の仕様変更や停止、利用制限があると表示できなくなる場合があります
- 非公開アカウントのポスト、削除済みポスト、取得できないポストは表示できません
- 引用リポストの引用部分は1段階のみ表示します(引用の引用は表示しません)
- Pommu の HTML 構造が変わると、リンク検出や挿入位置が合わなくなる場合があります
